## Important environment limitation

A real `npm install` / `npm run build` could not be completed in this execution environment because the npm registry was not reachable and the required CKEditor/DOMPurify packages were not available in the local npm cache.

Therefore this ZIP does NOT claim that the production Next.js build passed.

Before deployment, run:

```bash
npm install
npm run build
```

The root `package-lock.json` should also be regenerated by the successful `npm install`, because the current project already declares CKEditor and DOMPurify dependencies but the checked-in lockfile does not contain all of their transitive package entries.

Do not run the production seed against Atlas until you have verified the target database/environment.
